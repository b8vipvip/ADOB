# ADOB 生产就绪检查清单

[English](../PUBLICATION.md) | **简体中文** | [日本語](../ja-JP/PUBLICATION.md)

ADOB 是自动化开发智能体系统。本清单用于检查私有部署或多用户服务的生产准备情况。

## 控制服务

- [x] 受限制 MCP 工具及读写/破坏性标注。
- [x] 项目白名单和明确的 VSR/GHS 模式。
- [x] 不提供任意 Shell 或 SSH 工具。
- [x] 支持 Streamable HTTP 和 stdio。
- [x] 私有 HTTP 身份验证。
- [x] 正确区分排队、运行中和终态。
- [x] 最长五分钟等待及稍后复查。
- [ ] 公共多用户服务使用 OAuth 2.1 与 PKCE。
- [ ] 租户隔离的加密凭据存储。
- [ ] 限流、滥用防护和撤销能力。
- [ ] 持久审计和数据保留策略。

## GitHub

- [x] Fine-grained Token 权限说明。
- [x] 被管理仓库接入向导。
- [x] CI、部署、诊断、回滚和状态模板。
- [x] 固定可复用工作流版本。
- [x] GHS 固定 SSH 主机身份。
- [ ] 每个仓库启用分支保护或 Ruleset。
- [ ] Token 到期与轮换日历。
- [ ] VSR Runner 更新与隔离流程。

## VPS

- [x] GHS 使用非 root 部署账号。
- [x] 生产数据不参与源码同步。
- [x] 受限诊断和明确回滚确认。
- [ ] 经过验证的备份恢复流程。
- [ ] 磁盘、内存、健康和证书到期监控。
- [ ] 事故响应和紧急访问说明。
- [ ] 更换服务器后的恢复演练。

## 工作流行为测试

- [ ] 排队中的工作流报告为 pending，而不是失败。
- [ ] 运行中的工作流保持非终态。
- [ ] `wait_seconds=0` 返回可供并发工作的跟踪信息。
- [ ] 300 秒内完成时正确返回成功。
- [ ] 超过 300 秒仍运行时返回“仍在进行”。
- [ ] 只有 GitHub 给出终态失败结论后才报告失败。
- [ ] 首次运行未结束时不重复部署。
- [ ] 部署结束后才验证生产状态。

## 发布顺序

1. 运行类型检查、单元测试和容器构建。
2. 条件允许时分别测试 GHS 与 VSR。
3. 验证 pending、成功、失败和超时状态。
4. 验证脱敏 `ops-status`。
5. 检查 Secrets、Token 权限和主机公钥固定。
6. 创建版本标签，并让被管理项目固定到已评审版本。
7. 观察首次生产运行并确认部署 SHA。

## 必须由人完成的操作

未经授权的操作员参与，ADOB 不应自动执行账号所有权证明、验证码、支付、域名注册商操作、法律条款接受或首次高权限服务器初始化。
